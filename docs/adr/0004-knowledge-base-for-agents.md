# ADR-0004: База знаний для агентов — на английском, вшита в инструмент

**Статус:** принято

**Контекст.** Документация, которую читает модель, должна быть короткой, точной и не
расходиться с поведением компилятора.

**Решение.** `knowledge/llms.txt` — полный справочник; встроен в бинарник (`vard doc`,
`vard_doc` в MCP), поэтому версия справочника всегда совпадает с версией компилятора. Описания
элементов (`vard doc Text`) генерируются из `registry.rs`. Тексты для агентов — на английском
(меньше токенов, сильнее priors); документы для людей — на русском. `vard new` кладёт в проект
`AGENTS.md`, `CLAUDE.md`, скиллы и `.mcp.json`.

**Последствия.** + один источник правды; агент получает всё нужное одной командой. − при изменении языка нужно обновлять `llms.txt` и скиллы; фрагменты из скилла
`vard-app` живут в `examples/patterns` и проверяются `vard test`.
